# 제품 개요

## 무엇인가

정보처리기사 필기·실기 기출을 유형과 개념으로 분류하고, 개념별 출제 빈도와 회차별 출제 경향을 보여 주는 정적 웹사이트다. 공개 주소는 `https://DevMinGeonPark.github.io/Information-Processing-GISA/`이다.

공개된 구조화 기출 데이터셋이 없고 필기는 2022년 3회부터 CBT로 바뀌어 공식 문항이 공개되지 않는다. 이 프로젝트는 수험생이 복원한 기출을 메타데이터로 정리해 그 공백을 채운다.

## 대상 사용자

- 정보처리기사 수험생: 어떤 개념이 얼마나 자주 나왔는지를 근거로 공부 우선순위를 정하려는 사람
- 데이터 기여자: GitHub Pull Request로 기출 메타데이터를 추가·수정하는 수험생과 합격자

## 핵심 가치

| 기능 | 설명 |
|------|------|
| 유형화 | 문항마다 과목·개념 태그와 유형(용어형·개념이해형·계산형·코드해석형·SQL형·서술형) 1개를 부여 |
| 개념 빈도 랭킹 | 개념별 출제 문항 수와 등장 회차 수로 정렬한 표. 출제 0회 개념도 표시 |
| 잔디 히트맵 | 개념 × 회차 행렬을 GitHub contribution graph 형태로 표시. hover·키보드 포커스 툴팁 제공 |
| 회차별 경향 | 회차마다 유형 분포를 보여 주고, 필기와 실기를 구분해 표시 |
| 필터 | 트랙(필기·실기)·과목·기간·신뢰도(공식·복원)로 모든 화면을 즉시 다시 계산 |
| 커뮤니티 기여 | 기여 가이드, 이슈·PR 템플릿, base 브랜치 검증기 관문, 사이트 안 스니펫 도우미 |

## 범위 경계

- 문항 원문·보기·해설은 저장하지 않는다. 회차·과목·개념·유형·출처·신뢰도 같은 메타데이터만 기록한다
- 모든 분석 화면에 "복원 기출 기반, 공식 자료 아님" 안내 문구를 표시한다. 실기 3개 과목은 공식 과목이 아닌 분석용 분류임을 함께 밝힌다
- 데이터 범위 목표는 2020년 출제기준 개정 이후 전체 회차다. v1은 시드 2~3개 회차로 기능을 완성하고, 나머지는 데이터 트랙에서 채운다

### v1 비목표

- 문제 풀이·퀴즈·오답 노트, 계정과 학습 진도 저장
- 백엔드 서버, DB, 제출 API, 사이트에서 직접 PR을 만드는 기능
- 블로그·커뮤니티 자동 크롤링
- 방문자 분석, 광고, 다국어 UI

## 관련 SPEC

- `SPEC-TREND-001`: 데이터 계약, 검증기, 집계 코어, 분석 화면, CI·배포
- `SPEC-TREND-002`: 커뮤니티 기여 흐름 (`SPEC-TREND-001` 완료 후 진행)
