# 정보처리기사 출제 경향

정보처리기사 기출문제를 유형별로 나누고, 어떤 개념이 얼마나 자주 나왔는지 보여 주는 정적 사이트입니다. 필기와 실기를 모두 다루며 2020년 개정 이후 회차를 대상으로 합니다.

- 사이트: https://devmingeonpark.github.io/Information-Processing-GISA/

## 주요 기능

- **개념 빈도 랭킹**: 개념별 출제 문항 수와 등장 회차 수를 집계해 순위로 보여 줍니다.
- **잔디 히트맵**: 개념(행) × 회차(열) 행렬로 출제 강도를 색 농도로 나타냅니다.
- **회차별 추이**: 회차마다 문항 유형 분포를 필기·실기로 나눠 보여 줍니다.
- **출처 목록**: 집계에 쓰인 자료의 출처를 한곳에 모아 둡니다.
- **필터**: 시험 구분(필기/실기), 과목, 기간, 신뢰도(공식/복원)로 모든 화면을 다시 계산합니다.

## 데이터 정책

- 저장소에는 **문항 메타데이터만** 저장합니다. 회차, 과목, 개념 태그, 문항 유형, 출처, 신뢰도가 여기에 해당합니다.
- **문항 원문·보기·해설은 저장하지 않습니다.** 스키마가 원문 필드를 거부하며, `note`는 200자로 제한됩니다.
- 신뢰도는 `official`(공식 공개 문항)과 `reconstructed`(수험생 복원) 두 가지입니다.

> **주의**: 복원 문항에 기반한 집계는 추정치입니다. 실제 출제 내용과 다를 수 있으니 학습 방향을 잡는 참고 자료로만 활용해 주세요. 실기 분류(프로그래밍 / DB·SQL / 이론)는 공식 과목이 아니라 분석을 위해 나눈 분류입니다.

현재 데이터는 개발용 시드 3개 회차(2022년 1회 필기, 2024년 1·2회 실기, 회차당 6문항)이며 모두 `reconstructed`입니다. 문항 번호와 개념 매핑은 실제 시험과 대조하기 전의 임시 값입니다.

## 로컬 개발

Node.js 22.18 이상이 필요합니다.

```bash
npm install
npm test           # 단위·컴포넌트 테스트 (Vitest)
npm run validate   # data/ 스키마 및 규칙 검증
npm run dev        # 개발 서버 실행
npm run build      # 타입 검사 후 dist/ 빌드
```

데이터 구조는 `data/` 아래에 있습니다.

| 경로 | 내용 |
|------|------|
| `data/rounds.json` | 회차 목록 |
| `data/taxonomy.json` | 과목·주제·개념 분류 |
| `data/question-types.json` | 문항 유형 |
| `data/questions/<회차>.json` | 회차별 문항 메타데이터 |
| `data/schema/` | JSON Schema |

`main` 브랜치에 푸시하면 GitHub Actions가 검증·테스트·빌드를 거쳐 GitHub Pages에 배포합니다. Pull Request에서는 검증과 테스트만 실행합니다.
